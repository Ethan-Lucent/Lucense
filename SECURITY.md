
# Security Policy

## Supported Versions

Security fixes are prioritized for the latest stable release of Lucense.

Older releases may not receive security updates.

| Version | Security Support |
|---|---|
| Latest stable release | Supported |
| Older releases | Not guaranteed |
| Development builds | Not guaranteed |

## Reporting a Vulnerability

**Please do not disclose security vulnerabilities through public GitHub issues.**

If you discover a potential security vulnerability, report it privately.

Preferred reporting methods:

1. GitHub Security Advisories:
   https://github.com/Ethan-Lucent/Lucense/security/advisories/new

2. Direct contact with the maintainer:
   https://t.me/Eth4wn

When reporting a vulnerability, include:

- A clear description of the issue.
- The affected version or component.
- Steps to reproduce the vulnerability.
- Its potential impact.
- Proof-of-concept material, if available.
- Any suggested mitigation, if known.

Please avoid including real credentials, private cookies, personal files, or other sensitive information in reports.

## What to Expect

The maintainer will make a reasonable effort to:

1. Acknowledge the report.
2. Investigate and assess its severity.
3. Determine affected versions and components.
4. Develop and test an appropriate fix.
5. Coordinate disclosure when necessary.

Response times may vary depending on availability and severity.

## Security Considerations

Lucense aims to minimize unnecessary access to user data.

Security-sensitive areas include:

- Local music libraries and filesystem access.
- Downloading and processing external media.
- Third-party integrations and metadata providers.
- YouTube authentication and browser cookies.
- Network communication and proxy configuration.
- Automatic updates and downloaded binaries.
- Audio and metadata parsing.
- Local databases and backups.

Contributors should avoid introducing unnecessary permissions, unsafe file handling, insecure network communication, or accidental exposure of user data.

## Disclosure

Please allow the maintainer reasonable time to investigate and address a reported vulnerability before publicly disclosing it.

Coordinated disclosure helps protect Lucense users.
